# ATELIER // Moodboard Engine

An interactive, web-based spatial layout engine designed for fashion designers and visual artists.

## Tech Stack
- **Framework:** React + Vite 
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State & Canvas:** React Hooks, HTML5 Canvas API, Custom DOM Math Engine

## Features
- Infinite canvas viewport with spatial grid rendering
- Multi-element canvas manipulation (drag, scale, rotate, z-index layering)
- Full Undo/Redo history stack
- Preset fashion & textile inspiration moodboards
- Canvas export to JSON and high-res PNG

## Getting Started
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
